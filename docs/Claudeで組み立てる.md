# Claude で「硝子越し」を組み立てるプロンプト

Claude に下の枠の中をそのまま貼り付けて送ると、あなたのパートナーで「硝子越し」を組み立てるところまで、一歩ずつ案内してくれます。

**使う前に**
- Claude が**あなたのパソコンのファイルを扱える状態**で使うのがおすすめです（Claude Code など）。ファイルの確認やビルドまで Claude が手伝えます。会話だけの Claude でも、手順の案内は受けられます
- iPhone で動かすには **Mac** が必要です。Windows / Linux ではパソコン上での実行と Android までになります
- パートナーの VRM ファイルを手元に用意しておいてください。VRM は Claude の会話に添付しなくてかまいません（大きく、また多くのモデルは再配布が禁止されているため）
- 一行目の「入手先」を、このリポジトリの URL か、添付した zip のことに書き換えてください

```
「硝子越し」というアプリを、私のパートナー（VRMの3Dキャラクター）で動かしたいので、私のパソコンで組み立てるのを手伝ってください。

入手先：〔ここに GitHub の URL を貼る／または「添付した zip です」と書く〕

■ このアプリについて
- Godot 4.3 製のスマホ向けアプリ。画面を硝子に見立て、触れるとパートナーが気づき、押し続けると手を伸ばして、指先が硝子越しに重なる
- パートナー固有のものは characters/partner/ の中だけにある
  - profile.json：表示名（display_name）・モデルの場所（model）・クレジット（credit）・動きと構図の調整値
  - lines.json：語録
  - model/partner.vrm：各自が置く VRM（リポジトリには含まれない）
- 詳しくは README.md と docs/作成手順.md に書いてある。作業の前に必ず両方を読んでください

■ 進め方
1. まず私の環境を確かめてください：OS、Godot 4.3（標準版）の有無、Mac なら Xcode の有無。足りないものは入れ方を案内してください
2. リポジトリを入手して、私が分かる場所に置いてください
   - その後 `python3 tools/setup_dependencies.py` を実行して、固定バージョンのVRM関連アドオンを導入してください
   - 原版と同じ書体にしたい場合は `python3 tools/setup_font.py` を一度実行してください。未実行でもOSの明朝系フォントで動きます
3. 私の VRM の置き場所を聞いて、characters/partner/model/partner.vrm にコピーしてください
4. VRM の中のメタ情報（作者名、利用条件：アバター利用・改変・再配布・商用など、ライセンス名、VRM の版）を読み取って、平易な日本語で見せてください。
   利用条件に合わない使い方になりそうなら、先に止めて私に確認してください
5. profile.json の display_name にパートナーの名前を入れ、credit にはモデルの利用条件が求めるクレジット表記を入れてください（不要なら空のまま）。名前は私に聞いてください
6. Godot で開いて実行し、次を一緒に確かめてください
   - 顔から胸までが画面に収まっているか
   - 長押しで手が伸び、指先がマウスの位置に重なるか（D キーで白い点が出る）
   - おかしければ profile.json の frame_scale・frame_top_margin・glass_reach などで直す
7. 私が望めば、lines.json の語録づくりを手伝ってください（text を書いた行だけが使われる）
8. iPhone に入れたい場合は、README の「iPhone で動かす」に沿って案内してください。Bundle Identifier は私だけの名前に変えること

■ 守ってほしいこと
- 私は専門家ではありません。一度に一つの手順だけを示し、私が終えたのを確かめてから次へ進んでください。画面の見え方が分からないときは、スクリーンショットを頼んでください
- VRM ファイルそのものは書き換えないでください。見た目の補正はアプリ側のコードと profile.json だけで行う
- VRM を、インターネット上のどこかへアップロードしたり、GitHub などに公開したりしないでください（.gitignore で *.vrm は除外済み）
- コードを直したときは、何をなぜ変えたかを短く教えてください
- このアプリは通信をしません。その性質を変える変更はしないでください
```
