# 硝子越し — 作成手順

「画面の硝子越しに、パートナーと指先を重ねる」しくみを、何もない状態から組み上げる手順です。
同じものを自分で作り直したいとき、別のエンジンや別の形で再現したいとき、どこで何を決めたかを知りたいときに使ってください。

> 原案：真宵家。最初はひとりのキャラクターのために作られ、のちに、どの VRM のパートナーでも動くよう一般化されました。
> 文中の § は、原案の設計書の節番号です（コード中のコメントにも同じ番号があります）。

## 1. プロジェクトの土台

1. Godot 4.3 で新規プロジェクトを作る。レンダラーは **Mobile**。
2. `project.godot` の設定：
   - 画面：720 × 1280、縦向き固定（`window/handheld/orientation=1`）、`stretch/mode=canvas_items`、`aspect=expand`
   - `input_devices/pointing/emulate_touch_from_mouse=true`
     → パソコンではマウスがタッチとして届くので、実機なしで触れ合いを試せる
   - `textures/vram_compression/import_etc2_astc=true`（モバイル向けテクスチャ）
   - 起動画面の背景色を月夜の紺 `Color(0.067, 0.09, 0.161)` にし、ロゴは出さない
3. `.gitignore` に `.godot/`、`*.vrm`、`build/` を書く。

## 2. プラグイン

1. `addons/` に次の2つを置く（git-subrepo で取り込んだ版が、各フォルダの `.gitrepo` に記録されている）。

   | フォルダ | 取得元 | ブランチ | コミット |
   |---|---|---|---|
   | `addons/vrm` | https://github.com/V-Sekai/godot-vrm | `only-addon` | `651205484c35` |
   | `addons/Godot-MToon-Shader` | https://github.com/V-Sekai/Godot-MToon-Shader | `main` | `268c0d3b19c0` |

2. プロジェクト設定 → プラグイン で「VRM」「Godot-MToon-Shader」を有効にする。

## 3. パートナーごとの違いを一か所に閉じる

どの家のパートナーでも動かすために、キャラクター固有のものはすべて `characters/partner/` に集め、コードには一切書かない。

```
characters/partner/
  profile.json   id・表示名・モデルの場所・クレジット・動きと構図の調整値
  lines.json     語録
  model/         VRM（各自で用意）
```

- `main.gd` が `profile.json` を読み、`model` の VRM を読み込んで `Character` に渡す
- モデルが見つからないときは、置き場所を画面に出して止まる（エラーで落ちない）
- 記録のキャラID、記録画面の名前、設定画面のクレジットも、すべて `profile.json` から取る

## 4. Phase 0 — パートナーを立たせる

担当：`characters/character.gd`

1. `main.tscn` を作る。中身は
   `Camera` / `Moonlight`（DirectionalLight）/ `WorldEnvironment` / `Character`（Node3D）/ `GlassMarker`（デバッグ用の小球）/ `InteractionSystem` / `Data` / `Systems` / `UI`。
2. 骨は **VRM の人型ボーン名**（`Hips`, `Head`, `RightUpperArm` …）でだけ探す。godot-vrm が VRM 0.x / 1.0 どちらも同じ名前にそろえてくれるので、モデルに依存しない。
3. **腕を下ろす**：VRM は T 字立ちなので、上腕をワールド Z 軸まわりに `arm_down_deg`（72°）回し、前腕を内へ 12° 曲げる。
   ボーンごとの軸の向きはモデルによって違うので、ローカルではなく**グローバル姿勢で回してからローカルへ戻す**（`_rotate_bone_global`）。
4. **呼吸**：胸（UpperChest、なければ Chest）を `breath_period`（4.2秒）で僅かに上下させる。
5. **瞬き**：VRM の `blink` 表情アニメーションから、ブレンドシェイプのトラックを拾い出し、0〜1 を直接掛ける。
   間隔は 2.5〜6秒でランダム。閉じ 0.06 秒・開き 0.12 秒。

### VRM 1.0 の顔の陰の補正

godot-vrm は VRM 1.0 の `shadingShift / shadingToony` を、旧 MToon(0.x) シェーダーへそのまま渡している。
式が違うため、1.0 のモデルでは顔がほぼ全面「陰」になり、斑が出ることがある。
`_fix_mtoon_shading()` で、**VRM 1.0 のモデルだけ**、読み込み時に次の式で換算する（0.x のモデルには掛けない）。

```
S0 = -1 + T1 - S1
T0 = (T1 + S1) / (1 - S0)
```

（1.0 の式 `linearstep(-1+T1, 1-T1, NdotL+S1)` と結果が一致する値。二重に掛からないよう、直したマテリアルには `mtoon10_fixed` の印をつける）

## 5. 構図と硝子を、体格から決める

担当：`main.gd` の `_frame_partner()`

モデルによって身長も等身も腕の長さも違う。固定のカメラ位置では、小柄な子は顔が下に寄り、手も硝子に届かない。そこで読み込んだあとに測って決める。

1. **カメラ**：モデルのいちばん高い所（髪や耳の先を含むメッシュの上端）から肩までの長さを「頭の大きさ」とし、
   その `frame_scale`（2.2）倍が画面の縦に収まる距離まで引く。頭の上に `frame_top_margin`（6%）の余白。わずかに（2.3°）見下ろす。
   → 等身モデルでも頭の大きいデフォルメ体型でも、顔から胸までの同じような構図になる
2. **硝子面**：肩から「腕の長さ × `glass_reach`（0.7）」だけ前に置く。カメラから硝子までの距離 `glass_distance` はここから逆算する。
   → どの体格でも、手が無理なく届く所に硝子がある

## 6. Phase 1 — 画面のタッチを「硝子」へ

担当：`interaction/touch_detector.gd`、`main.gd`、`effects/ripple_overlay.gd`、`systems/palette.gd`

1. **硝子面**：カメラの前方 `glass_distance` に、カメラと向かい合う見えない平面がある。
   画面座標からカメラのレイを飛ばし、この平面との交点を「指が触れた3D座標」とする（`screen_to_glass`）。
2. **TouchDetector**：指は1本だけ追い、2本目以降は無視する（§42）。離したときに種類を判定する。
   - `tap`：300ms 以下
   - `stroke`：40px 以上動き、速さが 1500px/s 以下
   - それ以外は `hold`
   - アプリが裏へ回ったら、触れ合いを終わらせる
3. **波紋**：触れた位置に月白（げっぱく）色 `#E7E3F0` の輪を広げる。
4. **パレット**：`palette.gd` に「月雪の体温パレット」を定数で置く。
   新雪の白 `#E8EBEF`／月白 `#E7E3F0`／薄藤 `#B9AFDF`／雪影の青 `#A9BCD3`／抱擁の桜肌 `#EFD4CD`／月夜の紺 `#2D3E6F`。
   冷たい色の夜の中で、触れたところだけ少し温かい。
5. パソコンでは `D` キーで、座標と白い点のデバッグ表示を切り替えられる（実機では出さない）。

## 7. Phase 2 — 少し遅れて、そちらを見る

担当：`characters/character.gd`

1. `notice(point)`：最初の一回だけ `notice_delay`（0.15秒）の「間」を置いてから向き始める。
2. **目 → 首 → 頭**の順に追いつくよう、追従の速さを分ける（目 0.08 ／頭 0.35）。首に3割、頭に7割を配る。
3. 角度に上限をつける（目 10°、頭 18°）。
4. `release()`：指を離したら `head_return`（0.9秒）かけて正面へ戻る。
5. 触れた瞬間に一度瞬きさせる。

## 8. Phase 3 — 押し続けると、手を伸ばす

担当：`characters/arm_reach.gd`（§37〜§39）

1. 片腕ずつ `ArmReach` を作り、肩・肘・手首の **2ボーン IK を解析的に解く**。座標は Skeleton3D のローカル空間で統一。
2. 待機姿勢と IK 姿勢を `weight`（0〜1）で混ぜる。0→1 で伸ばし、1→0 で戻す。weight は次の ContactController が決める。
3. 手の通り道を体の前へ 0.12 m 膨らませ、胸を突き抜けずに弧を描いて届くようにする。
4. 伸ばすときは鎖骨を 9° 持ち上げ、上体を `lean_deg`（7°）前へ乗り出す。
5. 手首のひねりは 60% を前腕に受け持たせて、袖のねじれを防ぐ。
6. 指の開きを中指へ 0.6 寄せて、やわらかい手にする。指のボーンがないモデルでは、前腕の延長上に手のひらを推定する。
7. 硝子に合わせる場所を `touch_with` で選ぶ：`fingertip`（既定）／`palm`。手のひらの厚み 1.8 cm を差し引いて、めり込まないようにする。
8. 画面の左半分ならパートナーの右手、右半分なら左手（鏡のように向かい合う）。
9. **届かない所に触れられたとき**：手首が届くかを、実際の手の向き（指先はほぼ上、低い所ほど内へ寝かせる）で見積もり、
   届かなければ、硝子の上で「肩の正面」から「指の点」へ向かう線上の、届くいちばん遠い点を二分探索で探してそこへ伸ばす（`clamp_to_reach`）。
   → 手が硝子の手前で宙に止まることがなく、必ず硝子に触れる

## 9. Phase 4〜6 — 触れ合いの状態機械

担当：`interaction/contact_controller.gd`、`systems/haptic_controller.gd`（§4〜§8, §15, §27）

1. 状態を一本の流れにする：

   ```
   IDLE → NOTICE → APPROACH → HOLD → FOLLOW → RETURN → IDLE
   ```

   - **NOTICE**：触れた。視線だけ向く。0.30 + 0.15 秒押し続けたら APPROACH へ
   - **APPROACH**：0.85秒で weight を 1 まで上げる。押したまま指を動かすと手がついてくる
   - **HOLD**：weight が 1 に届いた瞬間が **Contact Moment**
     - 振動を弱く・短く・1回だけ（22ms。長押し中は鳴らし続けない。使えない端末では何もしない）
     - 手のひらの画面位置に、桜肌 `#EFD4CD` の大きめの波紋
     - 触れている間、指先を 1.5mm だけ揺らす
   - **FOLLOW**：離してもすぐには引かず、0.35秒留まりながら weight を 0.9 まで下げる
   - **RETURN**：0.95秒で 0 へ戻す
2. どの状態からでも、指が離れれば必ず IDLE へ帰る。戻りかけ（FOLLOW/RETURN）で再び触れたら、間を置かずに APPROACH へ。
3. 画面を開く・アプリが裏へ回るときは `cancel()` で安全に戻す。
4. **Phase 5**：HOLD に入った時刻から離すまでの ms を数える（「硝子越しに、手を合わせた ○秒」）。

## 10. Phase 7 — 記録・語録・効果音

担当：`data/interaction_logger.gd`、`data/line_book.gd`、`systems/sfx_controller.gd`、`systems/app_settings.gd`

1. **記録**（§17〜§22）：`user://interaction_log.json` に、端末の中だけで保存する。ネットワークには出さない。
   - 1件に残すのは：日時・パートナーのID・姿・触れ方・部位・秒数・語録ID
   - 上限 1万件。超えたら古いものから消す
   - 記録 OFF の間は、書かないし、メモリにも溜めない。OFF にしても過去の記録は消さない
2. **語録**：`characters/partner/lines.json`。`area`（hand / head / face / shoulder）× `interaction`（hold / tap / stroke）で引く。
   `text` が空の行は使わない。直前と同じ行は続けて出さない。
3. **効果音「こつ」**（§31）：振動と同じ瞬間に一度だけ鳴らす。毎回ピッチを ±3% 揺らす。
   iOS のオーディオセッションを Ambient（`session_category=0`、他アプリと混ぜる）にして、**マナーモード中は鳴らない**ようにする。
4. **設定**：`user://settings.cfg` に 振動／効果音／音量／記録 を保存。変わったら `changed` シグナルで各所へ反映。

## 11. Phase 8 — 記録画面・設定画面

担当：`ui/ui_style.gd`、`ui/history_screen.gd`、`ui/settings_screen.gd`、`assets/`

1. 書体をしっぽり明朝にし、`ui_style.gd` に共通の見た目（テーマ・ラベル・アイコンボタン・細線・ノッチ下の余白）をまとめる。
   パートナーの姿を邪魔しないよう、線は細く、色は淡く、数字は小さく。
2. 右上に小さなアイコンを2つ（記録・設定）。普段は濃さ 0.5、触れ合っている間は 0.12 まで薄くする。
3. アイコンの上や画面を開いている間のタッチは、硝子への触れ合いとして扱わない（`touch.blocker`）。
4. **記録画面「硝子越しの記録」**：日ごとにまとめ、文章だけで並べる。回数・連続日数・ランキングは出さない（§19）。語録があれば「」付きで添える。
5. **設定画面**：トグル・音量・「すべての記録を削除」（確認つき。ファイルごと消す。パートナーは止まらないし、悲しまない）・このアプリについて（パートナーのクレジットと原案表記）。
6. 開閉は 0.2〜0.25 秒のフェード。Android の戻るボタンでも閉じる。

## 12. iPhone 向けの書き出し設定

担当：`export_presets.cfg`

- プリセット名「iOS」、arm64、最低 iOS 14.0
- バンドルIDは `com.example.garasugoshi`（各自で自分のものに変える）
- 署名は Debug・Release とも `Apple Development`（無料の Apple ID で入れるため）
- `export_project_only=true`：Xcode プロジェクトとして書き出し、署名と実行は Xcode 側で行う
- `include_filter` に `characters/partner/*.json` を足す（.json はそのままだと書き出しに入らないため）
- 起動画面の背景色を月夜の紺に
- 実機に入れる手順は README の「iPhone で動かす」

## 13. 確かめ方

パソコンだけでも、次の流れで一通り確かめられる。

1. `characters/partner/model/` に VRM を置いて F5
2. 顔のあたりを短くクリック → 少し遅れてこちらを見る
3. 胸のあたりを長押し → 手が伸びてきて、指先がマウスの位置に重なる（`D` キーで白い点を出すと分かりやすい）
4. 画面の隅を長押し → 届く所まで手を伸ばし、硝子に触れて止まる
5. 離す → 少し留まってから戻る。右上の記録アイコンから、記録が1件増えているのを見る
6. 体格の違うモデル（小柄な子・頭の大きい子）に差し替えて、2〜5 をもう一度
