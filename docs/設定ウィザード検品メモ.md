# 設定ウィザード検品メモ

## 実装範囲

- Godot Editor 専用の `Partner Setup` プラグイン
- 初回のみ、モデル未設定ならウィザードを自動表示
- VRM ファイル選択とプロジェクト内へのコピー
- 名前・クレジット・語録3件・指先/手のひら・動きプリセットの保存
- 新しいVRMを選んだ場合の利用条件確認チェック
- 保存後の EditorFileSystem 再スキャン
- 既存モデルを残したまま設定だけ再編集可能
- iOS 書き出しから EditorPlugin を除外

## 静的確認

- `profile.json` / `lines.json` は既存形式を維持
- VRM は `.gitignore` の `*.vrm` 対象のまま
- ウィザードは `user://` の触れ合い記録には触れない
- ネットワーク処理を追加していない
- 同じ `partner.vrm` を選び直した場合は自己コピーを避ける
- `.vrm` 以外は保存時にも拒否する
- Godot 4.3 の `FileDialog.use_native_dialog` / `mode_overrides_title` APIに沿う

## Godot Editor で最終確認する項目

この検品環境には Godot 4.3 実行バイナリがないため、次はEditor上で確認します。

1. 初回起動でウィザードが1回だけ自動表示される
2. 左ドックと「プロジェクト → ツール」から再度開ける
3. macOS / Windows のファイルダイアログで `.vrm` を選べる
4. `partner.vrm` へコピー後、自動インポートが走る
5. 名前・クレジット・語録・触れ方・動きプリセットが保存される
6. F5で従来どおり硝子越しが動作する
7. iOS export に `addons/partner_setup/` が含まれない
