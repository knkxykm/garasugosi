# 5分で迎える — 超初心者版 README

これは、**VRM をすでに持っていて、Godot 4.3 をインストール済みの人**が、「硝子越し」に自分のパートナーを迎えて、まずパソコン上で触れ合うところまでの最短手順です。

> 「5分」は Godot のインストール時間、依存ファイルの初回取得、iPhone への初回書き出し時間を含みません。

## 用意するもの

- Godot 4.3（標準版）
- Python 3
- あなたのパートナーの `.vrm` ファイル
- この「硝子越し」フォルダ

VRM の利用条件は必ず確認してください。自作でないモデルは、アプリ利用・改変・再配布の可否が作者ごとに異なります。

---

## 0分目：最初の準備（初回だけ）

このリポジトリは配布を軽くするため、VRM読み込み用の外部プラグインを同梱していません。Godotを開く前に、プロジェクトのフォルダで次を1回実行します。

```bash
python3 tools/setup_dependencies.py
```

原版と同じ「しっぽり明朝」にしたい場合は、続けて次も実行します（任意）。

```bash
python3 tools/setup_font.py
```

どちらも**セットアップ時だけ**公式配布元へ接続します。硝子越しアプリ本体には外部通信処理はありません。

---

## 1分目：Godot で開く

1. Godot 4.3 を起動します。
2. **インポート** または **既存プロジェクトを開く** を選びます。
3. このフォルダにある `project.godot` を選びます。
4. 初回の読み込みが終わるまで少し待ちます。

画面の左側に **「硝子越し セットアップ」** が出ます。初回は「パートナーを迎える」画面が自動で開くこともあります。

出ない場合は、Godot 上部の **プロジェクト → ツール → パートナーを迎える** を選んでください。

---

## 2分目：VRM を選ぶ

「パートナーを迎える」画面で、

1. **VRMを選ぶ** を押す
2. あなたの `.vrm` ファイルを選ぶ
3. パートナーの名前を書く
4. クレジットが必要なら書く
5. VRMの利用条件を確認したチェックを入れる

選んだ VRM は `characters/partner/model/partner.vrm` へ**コピー**されます。元の VRM は移動・削除されません。また `.gitignore` により `.vrm` はGitへ追加されません。

---

## 3分目：その子らしさを少し足す

### 一言

「手を合わせたあとの一言」を3つまで書けます。空欄でも動きます。

### 触れ方

- **指先を合わせる**：既定
- **手のひらを合わせる**：掌で触れ合う

### 動き

- **静か**：間を大切に、ゆっくり
- **標準**：迷ったらこれ
- **活発**：視線や手の反応が少し早い

最後に **「この子を迎える」** を押します。

---

## 4分目：読み込みを待つ

Godot が VRM を読み込みます。モデルが大きいと少し時間がかかります。

エラーが出たら、まず次を確認してください。

- `.vrm` ファイルが壊れていないか
- VRM 0.x / 1.0 の一般的な人型モデルか
- `python3 tools/setup_dependencies.py` を実行したか
- Godot の「プロジェクト設定 → プラグイン」で VRM / MToon Shader / Partner Setup が有効か

---

## 5分目：触れてみる

キーボードの **F5** を押します。

- 顔の近くを短くクリック → 少し遅れてこちらを見る
- 画面を長押し → 手を伸ばしてくる
- 指先が届く → 「こつ」と Contact Moment
- 押したまま動かす → 視線と手がついてくる
- 離す → 少し留まってから戻る

パソコンでは、マウスがスマホの指の代わりです。

---

# あとから設定を変える

Godot 上部の **プロジェクト → ツール → パートナーを迎える** をもう一度開きます。

VRMを選び直さなければ、今のモデルを残したまま、名前・クレジット・一言・触れ方・動きだけ変更できます。

より細かく調整したい場合は、通常の [README.md](README.md) の「パートナーに合わせて調整する」を参照してください。

# iPhone に入れたい

通常の [README.md](README.md) の「iPhone で動かす」を参照してください。Mac・Xcode・Apple ID が必要です。

- 触れ合い記録に触らない
- 利用回数や連続日数を増やす仕組みを追加しない
- 実行中のアプリへネットワーク機能を追加しない

設計方針は [ETHICS.md](ETHICS.md) を参照してください。
